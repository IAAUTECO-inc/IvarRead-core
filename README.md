# IvarRead: Institutional CRM & Federated Analytics Hub

## 1. Overview
**IvarRead** is the institutional backbone of the IA_AUT_ECO ecosystem. Based on a hardened fork of **Kolix CRM**, it integrates advanced analytics and companion management for healthcare facilities and disability services.

## 2. Strategic Integration
* **Companion Sync:** Bi-directional bridge with Dragonborn (User App) and Winterhold OS (Edge Agents).
* **Federated Learning (Flower):** Aggregates insights from local nodes without ever compromising raw patient data.
* **Institutional Governance:** Specialized modules for HIPAA/GDPR compliance and resource orchestration.

## 3. Technical Foundation
* **Backend:** Hardened PHP/Go architecture.
* **Database:** Sovereign SQL implementation with Ysgrammor traceability.
* **Compliance:** ISO/IEC 5230 (OpenChain) certified supply chain.

## 4. Open Source Provenance
IvarRead is a downstream fork of Kolix CRM. We maintain full transparency regarding third-party libraries via our automated SBOM (Software Bill of Materials).
