# Security Policy (VDP)

## Supported Versions
Security maintenance is strictly enforced for the following versions:

| Version | Supported |
| :--- | :--- |
| 2.x.x | ✅ Active |
| 1.5.x | ⚠️ Critical Security Fixes Only |
| < 1.5 | ❌ End of Life (EOL) |

## Reporting a Vulnerability
Resilience and security are core architectural requirements. If you discover a vulnerability, please follow this protocol:
1.  **Do not open a public Issue.**
2.  Submit a detailed report to: `security@iaauteco.inc` (or via the platform's private disclosure channel).
3.  Include a Proof of Concept (PoC) and clear reproduction steps.

We will acknowledge receipt within 48 business hours and commit to a responsible disclosure timeline once a remediation is verified.
